# Engaged but Targeted? How Immigrants Vote Against Anti-Immigrant Agendas in Europe

**Younghyun Lee and Sanghoon Kim-Leffingwell**  
*Journal of Ethnic and Migration Studies*

[Read the paper](https://doi.org/10.1080/1369183X.2025.2589904)

## Overview

This repository contains replication materials for our study of immigrant voting behavior and support for anti-immigrant parties across Europe.

## Data Requirements

Replication requires European Social Survey (ESS) data from Rounds 9 and 10. The raw ESS files are not included because they exceed GitHub’s file-size limits.

Please download the required data from the [European Social Survey](https://www.europeansocialsurvey.org/) before running the replication code.
